# Qualitygate CLI book

[简体中文](../zh/README.md)

This book explains how to run snapshot-bound repository checks, convert
repository instructions into Schema-validated rules, interpret evidence,
integrate an Agent repair loop, and contribute to Qualitygate CLI.

1. [User guide](01-user-guide/README.md) — install, check, repair, and pilot.
2. [Reference](02-reference/README.md) — commands, rules, reports, evidence,
   exit codes, and limits.
3. [Architecture](03-architecture/README.md) — ownership, execution, data flow,
   and release boundaries.
4. [Contributor guide](04-contributor-guide/README.md) — development gates,
   fixtures, and requirement-to-test evidence.

For normative product requirements, use the
[CodeSpec requirements](../../codespec/requirements/qualitygate-cli.md).
For machine-governed repository navigation, use the
[CodeSpec map](../../codespec/codespec-map.yaml) and
[Knowledge map](../../knowledge/knowledge-map.yaml).
