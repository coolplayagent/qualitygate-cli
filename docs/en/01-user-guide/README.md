# Volume 1: User guide

[简体中文](../../zh/01-user-guide/README.md) · [Book](../README.md)

Follow this volume from a working installation to a repeatable acceptance
workflow. The rule-authoring chapter follows configuration; the final chapter
helps decide whether you need a separate real-world evaluation.

By the end, you should be able to select a snapshot, interpret its report,
configure reviewed checks and verify a repaired final delivery.
