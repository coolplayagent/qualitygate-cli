# 阶段 O：不依赖计价的 CLI 试点契约

> 日期：2026-09-17；工程验证，正式 8 项任务、7 天试点待启动。

新试点从 [v10 清单模板](../templates/pilot/observation-v10.json)开始。
用户无需提供人工时薪、计价来源/时间、币种或总金额上限。模板将
`budget` 与 `monetary_cap` 设为 null，不声明 `cost_ratio_max`。
CLI 仍要求 4 个修复、4 个重构任务，两个 Codex 模型组、两种流程，
每运行单元最多 3 次尝试/30 分钟、连续两次无进展停止，且要求来源、
初始 full 报告、执行顺序和逐尝试模型/执行记录。

`pilot seal` 接受无金额的 v10 完整候选计划。汇总仍把未提供的成本
标为未知，保留可用的用量与费用观察；最终签名主题由 evaluator v3
检查八项非财务阈值。检测、误报、修复、必需检查完成、复核比例、
匹配输入、审查时间减少和 full P95 耗时比都必须有证据且达标。
其他缺失证据和协议偏离仍阻止接受。已有 v1–v9 清单的预算、
成本比及签名主题语义保持不变。

| O-03 | `acceptance::tests::unpriced_pilot_requires_all_eight_nonfinancial_checks`：八项检查与失败/未知分离；旧 v1/v2 检查回归 |
| O-04 | Skill 包测试比较 v10 模板字节；release 工作流校验包内文件 |

本地工程检查和真实试点收益分开记录。没有独立真实任务、受信身份和
外部归档时，不生成正式封存、签名或收益结论。
