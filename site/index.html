Qualitygate CLI

Repository policy and task acceptance checks for software development. Each result is bound to the code and policy snapshot it checked, with violations and incomplete execution reported separately.

Download v0.5.0 Read the README

Install the Agent Skill

The release archive contains the Skill instructions, rule references, and matching Linux and Windows CLI binaries. For Codex on Linux or macOS, download and extract it into your skills directory:

gh release download v0.5.0 --repo coolplayagent/qualitygate-cli --pattern 'qualitygate-cli-skill-v0.5.0.tar.gz'
mkdir -p ~/.codex/skills/qualitygate-cli
tar -xzf qualitygate-cli-skill-v0.5.0.tar.gz --strip-components=1 -C ~/.codex/skills/qualitygate-cli

Windows users can extract the same archive and use its matching assets/windows-*/qualitygate.exe binary. Review the package layout and runtime rules before using it.

What the CLI checks

Snapshot-bound results

Run quick, staged, worktree, diff, or merge-request checks against a selected Git snapshot. Reports retain the policy and input identities needed to reproduce a result.

Repository rules

Use built-in rules, schema-validated project rules, required-file contracts, diagnostic debt ratchets, and bounded external command evidence.

Agent feedback

Give a coding agent bounded repair feedback while keeping policy changes, missing tools, and human acceptance visible as separate decisions.

Pilot evidence

Seal a model comparison plan, audit each attempt's model and execution records, and evaluate engineering thresholds without requiring financial estimates.

qualitygate selfcheck
qualitygate --root /path/to/repository check --worktree --profile quick --format json

Exit code 0 means a complete pass; 1 means blocking violations; 2 means the validation is incomplete.
