# Domain

This directory is governed by `knowledge/knowledge-map.yaml`. Update its map entry through `relay-knowledge map directory` and keep reviewed source material within the declared content scope.

Policy evolution separates navigation categories, unverified source evidence,
immutable candidates, independently validated revisions and signed active
policy. [The domain contract](../../docs/policy-evolution.md) records these
distinctions. [Effectiveness observations](../../docs/policy-validation.md#lifecycle-and-longitudinal-observations)
separate oracle validity, gate execution, downstream benefit and maintenance
cost; absent measurements remain unknown.
