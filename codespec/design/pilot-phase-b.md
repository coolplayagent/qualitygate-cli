## 反馈语义

领域层提供纯投影与资源限制；应用层运行检查、引用已经保存的完整报告；接口层选择输出。
不改变 `evaluate` 或退出码 0/1/2，不把精简输出当成新的验收依据。
完整报告保留全部诊断、证据和计划。精简反馈只把完成检查的诊断归入 findings；未完成检查的
原因和诊断放入 execution_gaps，不能从文案推断代码缺陷。gate blockers 独立保留引用。

同一指纹的诊断不自动合并；每项提供原报告索引，避免丢失成员身份。有限文本可截短，注明截断；
超出字节预算的完整项省略，逐类记录总量、已显示量、省略量。验收关联仅来自 plan.acceptance。
证据用原报告 JSON Pointer 引用，文件是否仍可访问由调用方读取和校验摘要，视图不声明可用。
复验 argv 只允许完整显示，预算不足时引用 context，不输出损坏的半条命令。
可选受限适配允许只读模型返回指定 `src/` 文件的严格 JSON 提案，控制器校验路径、旧内容和体积后写入，再完整复验。
错误发生在完整报告建立前时，沿用现有 incomplete 错误对象，不伪造反馈运行身份。

## 实际接入与观察边界

按用户约束继续使用同一 Codex 的 Terra/Luna 两组，均为 medium；不能关闭跨产品兼容性需求。
模型调用、修改和依赖构建均在隔离临时仓库进行；保护任务、测试与策略，所有失败留档。
每任务每组每流程最多 3 次尝试/30 分钟，连续 2 次无可验证进展停止。7 天收益观察、人工
复核与金额信息仍独立记录，工程测试通过不能缩短观察周期或补造人工收益。
