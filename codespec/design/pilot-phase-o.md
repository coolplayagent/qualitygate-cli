# 阶段 O：非财务试点验收契约

> 日期：2026-09-17；对应 EVO-05；正式 8 项任务、7 天试点尚未启动。

## 决策与边界

用户明确不要求人工时薪或计价。新计划使用 manifest schema v10，沿用 v9 的
8 项任务、7 天、32 个运行单元、来源、初始报告、交替顺序、逐尝试模型与
执行证据，以及签名授权/独立验收流程。`monetary_cap` 设为 null，
`budget` 与 `thresholds.cost_ratio_max` 不设值（模板分别使用 null 和省略）。
不得凭空补价格、人工时薪
或预算上限，也不得把 token 用量换算为完整货币成本。

| 编号 | 可执行要求 |
|---|---|
| O-01 | v10 可在没有金额参数时封存；v1–v9 继续使用原版金额约束。v10 拒绝非空的旧金额预算或成本比阈值。所有其他观察前约束保持必需。 |
| O-02 | v10 汇总仍可显示可得的用量和费用观察；缺价格时费用为未知，不污染质量、完成率、审查和耗时结果。 |
| O-03 | v10 最终主题使用 evaluator v3，恰好八项非财务检查：检测率、误报率、修复率、必需检查完成率、人工复核比例、匹配输入、审查时间减少、full P95 耗时比。任一已知未达标为失败，缺必需证据为未知；仅全部达标可签接受。v1/v2 evaluator 和主题摘要保持原语义。 |
| O-04 | CLI/Skill 发布相同 v10 模板，并保持旧模板可读取；发行包核对模板存在和字节一致性。 |

v10 取消的是金额验收，不是执行资源预算。每单元最多 3 次尝试、累计
30 分钟及连续两次无进展停止仍由 `attempt_audit` 判定；缺初始报告、
来源或逐尝试模型/执行记录仍不可完成。外部信任库、真实任务与独立人工
观察也不能由 CLI 生成。
